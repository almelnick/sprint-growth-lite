### Yardstick by Objective

Before any metric, decide which number judges this campaign.

- Maps each platform objective and optimization goal to the single number that decides the verdict.
- Splits metrics into yardstick (decides), diagnosis (explains) and vanity (ignored).
- Prevents the four classic mix-ups: traffic as awareness, CPM as awareness yardstick, video as awareness, downloads as purchases.
